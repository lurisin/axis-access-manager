# Security / Sicurezza

**English.** This add-on controls who can open doors. If you find a security problem, please do **not** open a public
issue. Report it privately from the **Security** tab of this repository (*Report a vulnerability*). Describe what you
found and how to reproduce it, without real names, card codes or passwords. Fixes are released as a new add-on
version; only the latest version receives them.

**Italiano.** Questo add-on decide chi apre le porte. Se trovi un problema di sicurezza, **non** aprire una issue
pubblica: segnalalo in privato dalla scheda **Security** di questo repository (*Report a vulnerability*). Descrivi cosa
hai trovato e come riprodurlo, senza nomi veri, codici di tessere o password. Le correzioni escono in una nuova
versione dell'add-on; le riceve solo l'ultima versione.
